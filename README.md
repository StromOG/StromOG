## 🌟 Engineering Philosophy

My work is built around a simple principle:

> **Write intentional code that respects both the hardware and the user.**

Rather than relying on bloated abstractions, I focus on understanding what happens underneath the hood — optimizing frame times, eliminating unnecessary allocations, and designing responsive, intuitive interfaces.

| Domain | What I Do |
| :--- | :--- |
| 🚀 **Client Optimization & JVM** | Designing modular engines for entity culling, chunk pacing, zero-allocation hot paths, and rendering performance |
